# 輸出範本

評估結果與學習路徑的空白 markdown 範本。SKILL.md 指向此處以保持主體精簡；實作範例與驗證規則仍留在 SKILL.md 中。

## 快速評估結果（Step 3A）

```markdown
## Claude Code 技能評估結果

### 你的等級：[Level 1：初學者 / Level 2：中階 / Level 3：進階]

你勾選了 **N/8** 個項目。

[根據等級給出的一句話勵志總結]

### 你的技能概況

| 領域 | 狀態 |
|------|--------|
| 基本 CLI 與對話 | [已掌握/缺口] |
| CLAUDE.md 與 Memory | [已掌握/缺口] |
| Slash Commands（內建） | [已掌握/缺口] |
| 自訂指令與 Skills | [已掌握/缺口] |
| MCP 伺服器 | [已掌握/缺口] |
| Hooks | [已掌握/缺口] |
| Subagents | [已掌握/缺口] |
| Print 模式與 CI/CD | [已掌握/缺口] |

### 已辨識的缺口

[針對每個未勾選項目，提供一行說明該學什麼，並附上教學連結]

### 你的個人化學習路徑

[輸出該等級專屬的學習路徑 — 見 Step 4]
```
