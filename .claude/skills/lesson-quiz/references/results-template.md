# 結果報告範本

Step 5（「計分並呈現結果」）的輸出格式。填入方括號中的佔位內容；標題與表格欄位請維持如下所示。

```markdown
## 課程測驗結果：[課程名稱]

**分數：N/10** — [等第標籤]
**測驗時機**：課程 [前 / 中 / 後]
**題型分布**：概念題答對 N 題，實作題答對 N 題

### 逐題結果

| # | 類別 | 題目（精簡） | 你的答案 | 結果 |
|---|----------|-----------------|-------------|--------|
| 1 | 概念 | [精簡後的題目] | [他們的答案] | [答對 / 答錯] |
| 2 | 實作 | ... | ... | ... |
| ... | ... | ... | ... | ... |

### 答錯的題目 — 請複習這些

[針對每個答錯的題目，顯示：]

**Q[N]：[完整題目文字]**
- 你的答案：[他們選的]
- 正確答案：[正確選項]
- 說明：[為什麼這是正確的]
- 複習：[該課程 README 中應重讀的具體章節]

### [時機專屬訊息]

[若為課前測驗]：
**課前測驗分數：N/10。** 這是你的基準線！把學習重點放在答錯的主題上。完成課程後再測一次，就能衡量你的進步。

[若為課程中]：
**進度檢查：N/10。**[若 7 以上：進展很好 — 繼續保持！若 5-6：繼續前請先複習答錯的主題。若 0-4：建議從頭重讀。]

[若為課程後]：
**精熟度檢查：N/10。**[若 9-10：你已精通本課程！可以前往下一課。若 7-8：就快到了 — 複習答錯的主題後再測一次。若 <7：請多花點時間在本課程，特別是上面標示的章節。]

### 建議的下一步

[根據分數與時機：]
- [若已精通]：前往學習路線圖中的下一課：[下一課連結]
- [若熟練]：複習這些特定章節後再測一次：[章節清單]
- [若發展中或以下]：重讀完整課程：[課程連結]。重點放在：[弱項類別清單]
- [提供選項]：「你想重測這份測驗、換一課測驗，還是針對某個主題求助？」
```
