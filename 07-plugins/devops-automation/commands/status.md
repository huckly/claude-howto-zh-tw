# 系統狀態檢查

檢查所有服務的系統健康狀態：

1. 查詢 Kubernetes Pod 狀態
2. 檢查資料庫連線
3. 監控 API 回應時間
4. 檢視錯誤率
5. 檢查資源使用率
6. 回報整體健康狀態
