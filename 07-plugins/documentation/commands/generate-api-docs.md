# API 文件產生器

產生完整的 API 文件：

1. 掃描 API 端點
2. 擷取函式簽名與 JSDoc
3. 依模組/端點組織
4. 建立含範例的 Markdown
5. 包含請求/回應結構
6. 新增錯誤文件
